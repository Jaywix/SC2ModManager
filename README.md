# SC2ModManager

## Setup

1. Download and install https://visualstudio.microsoft.com/
2. Inside the Visual Studio Installer, download and install `.NET desktop development` for work on `/SC2MMUpdater`, `/SC2ModManager` and `/SC2ReplayParser`.
3. (optional) Inside the Visual Studio Installer, also download and install `Desktop development with C++` for work on `/Injector32Helper`.
4. DONE! Now you can open `/SC2ModManager.sln` (with `Visual Studio` if Windows asks).
